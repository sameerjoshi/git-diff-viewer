Git Diff Viewer

A minimal, lightweight GitHub Desktop-style app for viewing diffs, staging files, and committing.

Built for Linux, where GitHub Desktop isn't officially available. Works on macOS and Windows too.

Download View on GitHub

Features

Unified diff view

Syntax-highlighted additions and deletions, just like GitHub.

Stage and commit

Stage individual files or all at once. Commit with summary and description.

Branch management

Switch branches, create new ones. Searchable dropdown with all local branches.

Real-time watching

File list auto-refreshes when files change on disk. No manual refresh needed.

Recent repositories

Quick access to previously opened repos. Open any folder via native picker.

No bloat

Vanilla HTML/CSS/JS. No framework, no build step. Two runtime dependencies.
